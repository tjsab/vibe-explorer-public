# Vibe Explorer

The meadow. Everyone is an Anon number. Tap once for the flute, press Sing for a tune, and Hide if you want the place to fill the phone.

Live: https://tjsab.github.io/vibe-explorer-public/?v=meadow-anon

GitHub Pages serves this build. People who open the link each get their own meadow. A shared live room needs a small server, which this host does not run.
